# ANIMEX ANIMAL HEALTH CARE PRIVATE LIMITED

Premier Veterinary Healthcare, Animal Feed Supplements, Mineral Mixtures & Livestock Nutrition Platform.

## Features
- **Brand Consistency**: Royal Navy Blue, Vibrant Orange, Emerald Green, Pure White palette.
- **Glassmorphism & Micro-animations**: Modern UI design with floating elements and responsive view toggles.
- **500+ Product Capacity**: Full multi-faceted search & filters by target species (Cow, Buffalo, Goat, Sheep, Poultry, Horse, Camel, Pig, Pet), disease, and category.
- **Disease Solution Directory**: Instant clinical mapping of diseases (Low Milk, Digestion, Liver Dysfunction, Calcium Deficiency, Infertility, Udder Care) to recommended products.
- **Dealer Locator Network**: Filter stockists by Indian state & district + online dealership application portal.
- **CMS Admin Panel**: Manage products, categories, dealer approvals, customer inquiries, and activity logs with CSV export.
- **Docker Infrastructure**: Containerized with PostgreSQL database, Prisma ORM, Redis caching, Nginx reverse proxy.

## Quick Start (Development)
```bash
# Install dependencies
npm install

# Run frontend development server
npm run dev

# Run Express REST API backend
npm run server
```
